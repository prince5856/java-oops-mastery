# Module 19: Design Patterns

## Key Patterns

### Creational
- **Singleton**: single instance; thread-safe variants.
- **Builder**: fluent construction.
- **Factory**: abstract object creation.

### Structural
- **Decorator**: add behavior dynamically.
- **Adapter**: bridge incompatible interfaces.
- **Proxy**: control access.

### Behavioral
- **Strategy**: encapsulate algorithms.
- **Observer**: notify changes.
- **State**: behavior changes with state.
- **Template Method**: skeleton in abstract class.

## Cheat Sheet

| Pattern | Use Case |
|---------|----------|
| **Singleton** | Single instance; config, logger. |
| **Builder** | Complex object construction. |
| **Factory** | Decouple creation. |
| **Strategy** | Interchangeable algorithms. |
| **Observer** | Event notification. |
| **Decorator** | Add behavior without modification. |
