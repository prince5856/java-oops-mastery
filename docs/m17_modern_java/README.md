# Module 17: Modern Java (15+)

## Key Concepts

### var Keyword (Java 10+)
- Local variable type inference.
- Compiler infers type from RHS.
- Improves readability in some cases.

### Switch Expressions (Java 14+)
- Pattern matching.
- Multi-value cases.

### Text Blocks (Java 15+)
- Multi-line strings.
- Preserves indentation.

### Sealed Classes (Java 17+)
- Restrict inheritance.
- `sealed class X permits Y, Z`.

### Pattern Matching (Java 16+, enhancing)
- `instanceof` with pattern variables.

## Cheat Sheet

| Concept | Key Takeaway |
|---------|--------------|
| **var** | Type inference; local variables. |
| **switch** | Expression form; pattern matching. |
| **Text Blocks** | Multi-line strings. |
| **Sealed** | Controlled inheritance. |
| **Pattern Matching** | Combine test + cast. |
