# Module 8: Object Relationships

## Key Concepts

### Association, Aggregation, Composition
- **Association**: objects are related but independent.
- **Aggregation**: one-to-many; "has-a" with independent lifetimes.
- **Composition**: one-to-many; "has-a" with dependent lifetimes (parent deletes child).

### Composition over Inheritance
- Prefer delegation (composition) to inheritance for flexibility.

## Cheat Sheet

| Concept | Key Takeaway |
|---------|--------------|
| **Association** | Loose coupling. |
| **Aggregation** | Independent lifetimes. |
| **Composition** | Dependent lifetimes; delete parent deletes child. |
