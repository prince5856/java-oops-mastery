# Module 20: Capstone - Low-Level Design (Machine Coding)

## Overview

Three realistic machine-coding problems:

### Problem 1: Parking Lot
- Design a parking lot system.
- Multiple levels, multiple parking spots.
- Reservation, cancellation, payment.
- Use OOP: encapsulation, inheritance, composition.

### Problem 2: Rate Limiter
- Implement a rate limiter (throttle requests).
- Token bucket or sliding window.
- Thread-safe; handle concurrent requests.
- Concepts: concurrency, data structures, algorithms.

### Problem 3: LRU Cache with Eviction Listener
- Implement Least-Recently-Used cache.
- Notify listeners on eviction.
- Concepts: linked structures, interfaces, generics, callbacks.

## Approach

1. Requirements and constraints.
2. Starter code (skeleton).
3. Full reference solution (with trade-offs).
4. Unit tests.
5. Interview discussion points.
