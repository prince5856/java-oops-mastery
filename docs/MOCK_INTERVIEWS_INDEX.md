### For Each Mock
1. **Set Timer**: 60 minutes
2. **Read Questions**: 10 minutes (don't solve yet)
3. **Code Problem**: 40 minutes
4. **Behavioral**: 10 minutes
5. **Check Answers**: Review your work
6. **Score**: Use rubric in answer file
7. **Reflect**: Note what went wrong

### Scoring Guide
- **90-100**: Interview ready for this level
- **75-89**: Good understanding, minor gaps
- **60-74**: Needs more practice
- **Below 60**: Review module, retake mock

## 💡 Tips for Mock Interviews

1. **Simulate Real Conditions**
   - Use a timer
   - No Google (only documentation)
   - Compile and test your code
   - Explain out loud

2. **Focus Areas**
   - Read the problem completely before coding
   - Ask clarifying questions
   - State your assumptions
   - Handle edge cases first

3. **Common Mistakes to Avoid**
   - Writing code without thinking
   - Forgetting null checks
   - Not testing edge cases
   - Not discussing trade-offs
   - Talking too much without coding

4. **After Each Mock**
   - Score yourself
   - Read the model answer
   - Understand what you missed
   - Note concepts to review
   - Plan what to study next
